# 互动卡片与出题约定

只在生成卡片或专题练习时读取。本文件补充展示与题目设计，不是固定题库。

## 根据能力选择展示

1. 有可用的原生交互工具：先读工具协议。卡片初始只显示题目和必要条件；支持“提示”“查看解析”和切换题目。选择题判定要依用户选择运行，不能每个选项都显示正确。
2. 无原生组件：默认逐题对话，一次出一道，等用户回复再评讲。不要用看似按钮的文字冒充可点击控件，不依赖未经确认可用的折叠标签。
3. 用户明确要可点击的文件卡片时，可制作独立 HTML，说明需要打开文件；不声称直接嵌入 Work。无需外部依赖或联网。交付前检查揭晓、提示、切题、边界、重置和键盘操作；未运行的部分如实说明。

在原生组件或 HTML 内，“还不熟 / 本轮通过”是自我标记；未接入真实回传时，不能声称助手已经看见点击或据此诊断。让用户把答案或困惑发回聊天。无持久化存储时不声称刷新或跨聊天仍保留状态。

## 题目与答案分离

每张卡片含一个明确考察目标。内部备有题目、充分条件、期望答案、决定性理由、提示、合理误区、变式；前面只显示题目所需信息。

涉及分子结构的题面优先调用结构生成参考与脚本，把代码生成的结构图放在题目旁。答案结构在揭晓前不生成到可见预览；不要把带答案的并排图、文件名、图片替代文字、标题或可下载校验元数据放在题面中。逐题对话时，等用户作答或请求解析后再生成并展示答案结构。

诊断题避免标题直接写出所考的反应机制而泄露答案。提示逐步揭晓，不一次显示全部。用户要求批量试卷时给完整题面并遵守其答案展示要求，不强制逐题模式。

选择题的干扰项对应具体误区，例如“只看底物级数”“把碱性当亲核性”“忽略环构象”。判题同时接受等价的正确表达或结构；开放题允许多个符合限制的合成路线。

学习记录的判据：

| 观察 | 合理记录 |
| --- | --- |
| 直接查看答案 | 已接触，尚未检验 |
| 提示后答对 | 能在提示下完成 |
| 结论正确，解释错误 | 结论正确，推理待修正 |
| 无提示答对新的条件变式且解释成立 | 本轮通过，之后再测 |

## 专题出题时检查

| 专题 | 优先考什么 | 出题前必须明确什么 |
| --- | --- | --- |
| 酸碱与共振 | 用共轭碱解释比较，而非背孤立数字 | 比较对象、溶剂或题设近似 |
| 取代与消除 | 同一底物改变条件后，机制与产物如何变 | 底物连接方式、试剂、溶剂、温度；判断所需的构象信息 |
| 烯烃/炔烃反应 | 电子流与区域、立体结果 | 试剂组合、反应顺序和后处理 |
| 芳香亲电取代 | 定位效应与活化/钝化的不同含义 | 原有取代位置、试剂与条件 |
| 羰基与烯醇负离子 | 亲核加成、酰基取代及反应位点 | 底物类别、碱/酸、当量和温度等决定性条件 |
| 立体化学 | 从明确空间关系推导构型与异构关系 | 楔线/投影约定、原子标签和观察方向 |
| 合成 | 骨架变化与正向路线验证 | 起始物、目标结构、允许的试剂或步数限制 |
| 波谱 | 多种证据联合排除候选 | 分子式、谱图/数据及单位；不能凭空补峰 |

## 逐题对话示例：只示范题面

题目：溴乙烷 CH3CH2Br 与 NaCN 在 DMSO（二甲基亚砜）中反应，温度 25 °C。预测主要有机产物，并说明最关键的一条判断依据。

回复“产物 + 理由”即可；需要帮助可以说“提示”。

实际使用时应先内部核验答案。不要把示例题的解析自动接在题面之后，也不要反复用同一道示例代替生成符合当前章节的新题。
